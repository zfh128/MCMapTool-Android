# MC Map Item Tool (手机 APP 版)

纯手机端（Termux + 命令行）打造的 MC 纯净地图画生成器，完美移植原版网页工具。

## ✨ 核心亮点
- **断网可用**：首次加载后自动缓存核心算法，开启飞行模式依然极速出图！
- **极简纯净**：原生 APK 壳，体积仅 100KB+，无任何第三方 SDK、无广告。VirusTotal 67 家杀软 0 报毒。
- **彻底解决卡顿**：完美解决手机浏览器上传图片卡“第三步”的痛点。
- **自动分类**：自带下载拦截，生成的 `.dat` 文件自动保存到 `Download/MCMapTool` 专属文件夹。

## 🚀 如何使用
1. 去右侧 **[Releases]** 页面下载最新的 `MCTool.apk` 并安装。
2. 打开 App 上传图片（建议 128x128 像素的图）。
3. 走完 5 个步骤后点击下载。
4. 去手机文件管理器的 `Download/MCMapTool` 里找到 `.dat` 文件，丢进 MC 存档即可。

## 💻 极客玩法
本项目代码完全开源，你甚至可以利用 Termux 部署本地 Node.js 服务器，实现 100% 纯离线运算（详细源码见 Releases 附件）。
